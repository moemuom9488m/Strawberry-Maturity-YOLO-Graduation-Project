3. **10cm 空間點雲去重**：設計並部署了 $10\text{cm}$ 歐氏距離點雲去重與多訊框屬性均值融合算法，防止果實重覆計數。
⚠️ **遇到問題**：
1. **導航與投影邏輯不一致**：原系統採用無人機俯視圖單應性（Homography）投影，與實車搭載雙側側拍鏡頭在溝渠行駛側拍的實務物理現狀衝突，且原 Skip-Row (跳行) 演算法無法達到 $100\%$ 每行通道全覆蓋的要求。
2. **終端 Big5 (CP950) 亂碼報錯**：PowerShell 於 Windows 環境下在輸出含有草莓 emoji `🍓` 及 ✅ 等中文字元時產生 `UnicodeEncodeError` 崩潰。
💡 **解決方式**：
1. **重構 CCPP 規劃器**：將 `astar_planner.py` 與 `SAM2D+AStar路徑規劃.ipynb` 透過 Git 優雅地重命名為 `ccpp_planner.py` 與 `SAM2D+CCPP路徑規劃.ipynb`。全面用 `CCPPPlanner` 替換 `AStarPlanner`。
2. **重新編寫雙側側拍投影仿真**：於 `step2_projection.py` 模擬完整的雙側動態探測，加入隨機高斯感測噪聲及 $10\text{cm}$ 空間點雲歐氏去重融合，大幅提高數位孿生之真實度。
3. **中文/Emoji 編碼防護**：所有 Python 工具程式（包括 `fix_notebook.py`）開頭均強制設置 `sys.stdout.reconfigure(encoding='utf-8')`，並在命令列前加入 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 完美杜絕亂碼及 Unicode 報錯。

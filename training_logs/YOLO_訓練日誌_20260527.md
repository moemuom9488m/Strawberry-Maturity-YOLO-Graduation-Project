🎯 **訓練策略**
- 目的: 開發自動化 YOLO 實驗多維度對照分析工具 `agent_tools/yolo_comparator.py`，用以分析並視覺化不同 YOLO 訓練實驗 (results.csv) 的關鍵指標 (Precision, Recall, mAP50, mAP50-95, Loss)。
- 功能特點: 
  1. 自動掃描 `runs/detect/` 下的所有實驗結果。
  2. 提取「最佳模型狀態」與「最終模型狀態」的關鍵數據。
  3. 平滑化學習曲線並標記最佳 Epoch，輸出高質感對比圖。
  4. 自動輸出 CSV 表格與 Markdown 報告至 `evaluation_results/`。

---

⚠️ **遇到問題**
1. **Unicode cp950 編碼報錯**: 
   - 由於腳本最初在 `print` 訊息中使用了 Emoji 字元（如 `🔍` `✅` `❌` `📊` `🍓` 等），而在 Windows 的 cp950 語系環境下，即便使用 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 啟用 UTF-8，Python 依然以 cp950 解讀 stdout 造成 `UnicodeEncodeError`。
2. **Missing Dependency 'tabulate'**: 
   - 呼叫 Pandas DataFrame `to_markdown()` 來產出 Markdown 表格時，由於 `pytorch` 環境中沒有安裝 `tabulate` 庫，造成 `ImportError: Missing optional dependency 'tabulate'`。

---

💡 **解決方式**
1. **移除非 ASCII / 非 CP950 敏感符號**: 
   - 徹底移除 `print` 中所有的 Emoji 符號，改用標準乾淨的文字框字首標籤，如 `[SCAN]`, `[OK]`, `[SKIP]`, `[LOADED]`, `[PLOT]`, `[EXPORT]` 等，完美避開 Windows 終端機編碼死角。
2. **手動 Markdown 表格產生器**: 
   - 不再依賴 Pandas 的 `to_markdown()` 方法，而是利用簡單的字串拼接，編寫一個自訂的 Markdown 表格生成程式碼段，完全免除對第三方 `tabulate` 庫的依賴，大幅提升了腳本的相容性與可移植性。
3. **成果確認**:
   - 重新執行 `python agent_tools/yolo_comparator.py` 完美無阻礙通過，成功產出 `evaluation_results/` 底下的所有圖表與 Markdown 實驗報告！

---

⚠️ **遇到問題**
1. **Matplotlib 字型缺失警告 (Emoji Warning)**:
   - 在圖表標題與浮水標籤中使用了 `🍓` 與 `💡` 符號，Matplotlib 在以 `Microsoft JhengHei` (微軟正黑體) 進行 PDF/PNG 存檔渲染時，會發出 `UserWarning: Glyph missing from font(s)` 的警告，且 Emoji 符號會顯示為空白方框。
2. **圖表元素與標註視覺重疊**:
   - 決策結論框原先位置偏低，部分遮擋了第一與第三個柱子頂端的精度標註（`0.8699` 與 `0.8692`）。
   - 紅色折線點上的時間標註與柱子精度標註高度太接近，產生交叉重疊，影響簡報的美觀度與閱讀體驗。

---

💡 **解決方式**
1. **圖表文字純淨化**:
   - 將 Matplotlib `plt.title` 和決策方框中的所有 Emoji 符號移除，改用純中文格式（例如將 `💡` 改為中括號 `【關鍵決策結論】：`），確保在任何 Windows 系統下均能 100% 渲染乾淨且無任何警告。
2. **雙向拉升與標註偏移自癒**:
   - **解決決策框遮擋**：將左側 Y 軸上限拉高至 `0.925`，使頂端空出寬敞的天空。並將決策結論框的 Y 座標上移至 `0.78`，使其完美漂浮於 `0.88 - 0.92` 的空白天空區，不再遮擋任何數據。
   - **解決數據標註重疊**：將折線圖上的時間標註（`63.9 hr` 等）偏移量改為向下偏移 `22` 點（`xytext=(0, -22)`）。使折線數值位於紅點下方、柱子數值位於柱頂上方，兩者一上一下，徹底消除交叉重疊。
3. **成果確認**:
   - 重新執行 `python agent_tools/draw_ppt_chart.py` 通過，成功產生無遮擋、無重疊且超高品質的簡報對照圖 `evaluation_results/ppt_model_selection_comparison.png`！
